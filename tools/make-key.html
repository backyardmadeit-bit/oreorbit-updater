OreOrbit update key

Runs only in this browser window. Nothing is sent anywhere.

A. Make a new key

1. The key goes into GitHub as the secret ATLAS_KEY. Keep it private.

2. The fingerprint goes on your website: in WebFTP, open atlas/update-config.php, click Edit, replace the whole file with this one line and save.

B. Or check a key you already have

Paste the key from your old scheduled task. If the fingerprint matches the one in update-config.php, you can use that key as ATLAS_KEY and change nothing on the website.
